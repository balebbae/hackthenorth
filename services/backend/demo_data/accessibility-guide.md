# Step-free access — demo site
Need to go upstairs without using stairs? Use the East Elevator.
It serves the upper floors and is the mapped accessible option for vertical access.
From the entrance the mapped ground-floor route to its door is 12 metres.
The stairwell is NOT a step-free route. Restroom on ground floor has an accessible tag.
Maintenance availability: not supplied. Do not infer that the elevator is operating now.
Upper-floor routing geometry has not been surveyed in this demo.
