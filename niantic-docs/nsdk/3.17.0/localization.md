# Localization

</div>

With the recent update to NSDK 4.0, here are some key points to keep in mind for those that still have projects using ARDK 3.17

1.  Your existing workspaces, projects, POIs, scans, and assets are copied into a new schema and mapped into Scaniverse
2.  POIs will continue to work as they've been working without the need for any additional scanning
3.  All existing apps using the old API key method will continue to work with their API keys
    1.  Any new projects should be targetting NSDK 4.0, this is only for pre-existing 3.x projects
4.  Projects remaining on 3.x will not be able to make use of VPS2 and its improvements; VPS2 will only be available for NSDK 4.x projects
