# Supported Devices

</div>

Lightship ARDK is able to run on all devices that support <a href="https://developers.google.com/ar/devices" target="_blank" rel="noopener noreferrer">ARCore</a> and <a href="https://developer.apple.com/library/archive/documentation/DeviceInformation/Reference/iOSDeviceCompatibility/DeviceCompatibilityMatrix/DeviceCompatibilityMatrix.html" target="_blank" rel="noopener noreferrer">ARKit</a>. Please refer to their respective help pages for more details. Some ARDK features, such as depth, semantics and meshing, require significant computational resources to deliver a smooth experience. For AR experiences using those features, we recommend at least an iPhone 7, a high-end Android device from 2018 or later, or a mid-tier Android device from 2022 or later.
