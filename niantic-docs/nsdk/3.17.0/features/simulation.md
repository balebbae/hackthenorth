# XR Simulation

</div>

Lightship XR Simulation extends the <a href="https://docs.unity3d.com/Packages/com.unity.xr.arfoundation@5.1/manual/xr-simulation/simulation-overview.html" target="_blank" rel="noopener noreferrer">base Unity simulation package</a> to support testing Lightship features in XR simulation. This feature allows you to test your application in the Unity editor by loading it in a virtual environment where you can freely move the camera and make sure all your XR content works as expected. Inside the simulation, ARFoundation features such as Plane Tracking and Image Tracking work alongside Lightship features like Meshing, Scene Segmentation, and Object Tracking.

## Learn more<a href="#learn-more" class="hash-link" aria-label="Direct link to Learn more" title="Direct link to Learn more">​</a>

For instructions on installing Lightship Simulation, see the [XR Simulation How-To](https://www.nianticspatial.com/docs/nsdk/3.17.0/how-to/unity/simulation_mocking/).
