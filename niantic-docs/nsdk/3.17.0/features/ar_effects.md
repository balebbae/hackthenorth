# AR Effects

</div>

<span class="page-subtitle">Tools for grounding your virtual content in the real world</span>

<div class="opener">

NSDK provides real-time understanding of the physical world by capturing depth and generating meshes, which enabling content to be situated realistically in the real world through occlusions.

Depth, Occlusion, and Meshing work on any device, regardless of lidar capability, at greater distance than lidar-based AR. These systems override and extend the base AR Foundation managers seamlessly with no work needed by the user if they already have an AR Foundation project.

</div>
