# Navigation Mesh

</div>

Navigation Mesh provides a straightforward interface to control the movement of virtual content by creating a grid of tiles on top of flat surfaces in the scene. This allows assets to use the grid to move through space naturally and navigate around obstructions (such as tables or chairs) or even jump on top of them.
