# class LightshipNavMeshRenderer

</div>

(Niantic.Lightship.AR.NavigationMesh.LightshipNavMeshRenderer)

[LightshipNavMeshRenderer](https://www.nianticspatial.com/docs/nsdk/3.17.0/apiref/Niantic/Lightship/AR/NavigationMesh/LightshipNavMeshRenderer/) is a helper MonoBehaviour which will draw the [LightshipNavMesh](https://www.nianticspatial.com/docs/nsdk/3.17.0/apiref/Niantic/Lightship/AR/NavigationMesh/LightshipNavMesh/) tiles If you want to draw the [LightshipNavMesh](https://www.nianticspatial.com/docs/nsdk/3.17.0/apiref/Niantic/Lightship/AR/NavigationMesh/LightshipNavMesh/) in a custom way you can create a similar renderer e.g. stylize the board as water/snow/sand etc.
