# class LightshipNetworkObject

</div>

(Niantic.Lightship.SharedAR.Netcode.LightshipNetworkObject)

The [LightshipNetworkObject](https://www.nianticspatial.com/docs/nsdk/3.17.0/apiref/Niantic/Lightship/SharedAR/Netcode/LightshipNetworkObject/) is a component to add to the colocalized objects. Essentially, [LightshipNetworkObject](https://www.nianticspatial.com/docs/nsdk/3.17.0/apiref/Niantic/Lightship/SharedAR/Netcode/LightshipNetworkObject/) bring [Netcode](https://www.nianticspatial.com/docs/nsdk/3.17.0/apiref/Niantic/Lightship/SharedAR/Netcode/) for Gameobjects NetworkObject and re-parent the object under the Shared [AR](https://www.nianticspatial.com/docs/nsdk/3.17.0/apiref/Niantic/Lightship/AR/) Origin when spawned.
