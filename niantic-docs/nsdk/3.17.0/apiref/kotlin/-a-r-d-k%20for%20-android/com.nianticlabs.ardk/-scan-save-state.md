# ScanSaveState

</div>

\[androidJvm\]\
enum [ScanSaveState](https://www.nianticspatial.com/docs/nsdk/3.17.0/) : <a href="https://kotlinlang.org/api/latest/jvm/stdlib/kotlin-stdlib/kotlin/-enum/index.html" target="_blank" rel="noopener noreferrer">Enum</a>\<[ScanSaveState](https://www.nianticspatial.com/docs/nsdk/3.17.0/)\>

Enumeration of possible scan recording save states.

This enum represents the current state of a scan recording operation, indicating whether the scan data has been successfully saved, discarded, or failed.
