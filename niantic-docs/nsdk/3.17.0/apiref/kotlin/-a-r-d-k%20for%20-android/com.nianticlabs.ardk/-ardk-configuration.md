# ArdkConfiguration

</div>

\[androidJvm\]\
object [ArdkConfiguration](https://www.nianticspatial.com/docs/nsdk/3.17.0/)

Kotlin configuration structures mirroring Swift `ArdkSession.Configuration`.

These are value types used to construct a full ARDK configuration when callers want explicit control over all parameters (vs. using defaults or JSON file).

The nested types correspond to ARDK C-ABI structs and are intentionally nullable to allow partial specification, matching Swift's optional fields.
