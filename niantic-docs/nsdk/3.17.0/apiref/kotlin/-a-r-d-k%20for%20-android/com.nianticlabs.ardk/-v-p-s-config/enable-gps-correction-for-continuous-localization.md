# enableGpsCorrectionForContinuousLocalization

</div>

\[androidJvm\]\
val [enableGpsCorrectionForContinuousLocalization](https://www.nianticspatial.com/docs/nsdk/3.17.0/apiref/kotlin/-a-r-d-k%20for%20-android/com.nianticlabs.ardk/-v-p-s-config/enable-gps-correction-for-continuous-localization/): <a href="https://kotlinlang.org/api/latest/jvm/stdlib/kotlin-stdlib/kotlin/-boolean/index.html" target="_blank" rel="noopener noreferrer">Boolean</a> = true

Whether to enable GPS correction for continuous localization.

This will download additional GPS graph data from the VPS server to help correct the GPS location of the device. This is useful for refining device GPS location after localization.

**Default:**`true`
