# cloudInitialRequestsPerSecond

</div>

\[androidJvm\]\
val [cloudInitialRequestsPerSecond](https://www.nianticspatial.com/docs/nsdk/3.17.0/apiref/kotlin/-a-r-d-k%20for%20-android/com.nianticlabs.ardk/-v-p-s-config/cloud-initial-requests-per-second/): <a href="https://kotlinlang.org/api/latest/jvm/stdlib/kotlin-stdlib/kotlin/-float/index.html" target="_blank" rel="noopener noreferrer">Float</a> = 1.0f

Defines the number of localization requests per second which are sent to the VPS server prior to the first successful localization.

This is 1.0f in the default configuration.

**Default:**`1.0f`**Range:** 0.1f - 5.0f (recommended)
