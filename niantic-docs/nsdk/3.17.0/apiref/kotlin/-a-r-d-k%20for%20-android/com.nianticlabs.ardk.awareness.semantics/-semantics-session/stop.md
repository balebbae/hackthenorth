# stop

</div>

Stops the semantics session.

This halts semantics processing while keeping the native semantics session loaded. You can restart semantics later with [start](https://www.nianticspatial.com/docs/nsdk/3.17.0/apiref/kotlin/-a-r-d-k%20for%20-android/com.nianticlabs.ardk.awareness.semantics/-semantics-session/start/).
