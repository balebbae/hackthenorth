# start

</div>

\[androidJvm\]\
fun [start](https://www.nianticspatial.com/docs/nsdk/3.17.0/apiref/kotlin/-a-r-d-k%20for%20-android/com.nianticlabs.ardk.mapping/-device-mapping-session/start/)()

Start the mapping session.

This starts some underlying processes that need to be running before actual mapping can begin, downloading the model containing the mapping algorithm. It does not actually start the map building process, which needs to be invoked separately with [startCreating](https://www.nianticspatial.com/docs/nsdk/3.17.0/apiref/kotlin/-a-r-d-k%20for%20-android/com.nianticlabs.ardk.mapping/-device-mapping-session/start-creating/).
