Logs the contents of this <a href="https://developer.android.com/reference/kotlin/android/graphics/Matrix.html" target="_blank" rel="noopener noreferrer">Matrix</a> as a 3×3 matrix.

The matrix values are printed in row-major order, as used internally by <a href="https://developer.android.com/reference/kotlin/android/graphics/Matrix.html" target="_blank" rel="noopener noreferrer">android.graphics.Matrix</a>. Useful for debugging transformations like scale, rotation, skew, and perspective.
