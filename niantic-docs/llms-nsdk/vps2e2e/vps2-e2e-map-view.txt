# Select a Site and anchor payload

This page implements the Select a Site and anchor payload step in the wayfinding workflow. In this workflow, the user browses Sites on a map, selects a Site with a Production VPS asset, and passes its anchor payload into the AR flow. The Kotlin implementation on this page uses the Mapbox-based approach from the enterprise Kotlin VPS2 end-to-end sample: the app loads Organizations, centers the map on the user's current or default location, renders eligible Sites as pins, and opens a site panel that launches VPS2 with the chosen payload.

(image: After initializing a wayfinding app, select a Scaniverse Site and anchor payload.)

*Figure:* Previous steps of the tutorial showed how to initialize the app and route the user into the Sites flow. This step shows how to implement Site selection, and next steps show VPS2 localization, and AR wayfinding.

## Files Overview

The Select a Site and anchor payload step has four steps:

1. [Create the map screen](#create-the-map-screen).
2. [Manage Sites data and state](#manage-sites-data-and-state).
3. [Load and filter Sites for VPS2](#load-and-filter-sites-for-vps2).
4. [Render site pins and select a Site](#render-site-pins-and-select-a-site).

Your app can organize those responsibilities in different files. The following table shows one way to structure them in a standalone app shown in this tutorial, along with the names of the matching files in the Kotlin `vps2e2e` sample with the corresponding functionalities.

| Responsibility | Standalone app | Sample reference |
|------|------|------|
| Create the map screen | `WayfindingSitesView.kt` Compose map UI, viewport state, and map overlays | `SitesView.kt` |
| Manage Sites data and state | `WayfindingSitesManager.kt` state and SDK orchestration and `WayfindingSitesState.kt` navigation states and models | `SitesManager.kt` and `SitesState.kt` |
| Load and filter Sites for VPS2 | `WayfindingSitesManager.kt` loads Organizations, selects the current Organization, and filters Sites for Production VPS assets | `SitesManager.kt` |
| Render site pins and select a Site | `WayfindingSitesView.kt` renders map pins, site details, and navigation into VPS2 | `SitesView.kt` and `VPS2Route.kt` |

## Create the map screen

This step creates the map-based Sites screen. It adds the map dependencies and access token, creates `WayfindingSitesView.kt`, and routes the app into that screen so the next steps can load Organizations, render pins, and launch VPS2 from the map.

This step has four parts:

1. [Add map dependencies](#add-map-dependencies) to enable the Mapbox map and device-location helpers.
2. [Add a map token](#add-a-map-token) so the map SDK can load map tiles.
3. [Create the Sites map screen](#create-the-sites-map-screen) so the Sites route opens a full-screen map.
4. [Open the map screen](#open-the-map-screen) so the app uses `WayfindingSitesView.kt` instead of the earlier placeholder.

### Add map dependencies

In an existing app, update your app module so it includes the dependencies needed for the map screen. If you are unsure how to implement this step, use the following new app example as a reference.

This step should:

- Include the Mapbox Maven repository in Gradle dependency resolution.
- Include the Mapbox Android SDK dependency.
- Include the Mapbox Compose extension dependency.
- Include the Google Play Services location dependency.

1. In your project-level `settings.gradle.kts`, add the Mapbox repository to the existing `dependencyResolutionManagement { repositories { ... } }` block, not the `pluginManagement { repositories { ... } }` block:

   ```kotlin
   }
   ```

2. Add the map dependencies to the `dependencies { ... }` block in `app/build.gradle.kts` as shown in the following code example:

   ```kotlin

   implementation("com.mapbox.extension:maps-compose:11.22.0")
   implementation("com.google.android.gms:play-services-location:21.0.1")
   ```

### Add a map token

In an existing app, update your current map configuration so the map SDK can read a Mapbox access token. If you are unsure how to implement this step, use the following new app example as a reference.

This step should:

- Store the Mapbox access token in an Android resource.
- Keep that token outside the Kotlin source file.
- Use a Mapbox public access token so the app can load map tiles.

In a new app, add a Mapbox access token with the following steps:

1. [Create a Mapbox account](https://www.mapbox.com/signup/) if you do not already have one and follow the prompts to create a free account.

2. Create a Mapbox public access token. Sign in to your Mapbox account, open the **Access Tokens** page in the Mapbox Developer Console, and copy a public token that starts with `pk.`.

3. In Android Studio, create a new **Values Resource File** by expanding `app/src/main/res/values`, expanding the `values` menu, selecting **New > Values Resource File**, and entering `mapbox_access_token` as the file name.

4. Create `app/src/main/res/values/mapbox_access_token.xml` as shown in the following code example:

   ```xml
   <resources xmlns:tools="http://schemas.android.com/tools">
       <string name="mapbox_access_token" translatable="false" tools:ignore="UnusedResources">YOUR_MAPBOX_ACCESS_TOKEN</string>
   </resources>
   ```

5. Replace `YOUR_MAPBOX_ACCESS_TOKEN` with your Mapbox public access token.

### Create the Sites map screen

In an existing app, update your current Sites or destination selection screen. If you are unsure how to implement this step, use the following new app example as a reference.

The map screen should:

- Receive the shared `NSDKSessionManager`.
- Receive the app `NavHostController`.
- Display a full-screen map.
- Track the current viewport and selected map style.
- Load the user's current location or fall back to a default starting point.
- Reserve space for the overlays and Site-selection UI that later steps add.

In a new app, create `app/src/main/java/<your app package path>/WayfindingSitesView.kt` as shown in the following code example:

#### Expand to view WayfindingSitesView.kt

```kotlin
package com.example.wayfinding // Replace with your app package name

import android.Manifest
import android.content.Context
import android.content.pm.PackageManager
import androidx.compose.foundation.layout.Box
import androidx.compose.foundation.layout.fillMaxSize
import androidx.compose.material3.ExperimentalMaterial3Api
import androidx.compose.runtime.Composable
import androidx.compose.runtime.getValue
import androidx.compose.runtime.LaunchedEffect
import androidx.compose.runtime.MutableState
import androidx.compose.runtime.mutableStateOf
import androidx.compose.runtime.remember
import androidx.compose.runtime.setValue
import androidx.compose.ui.Modifier
import androidx.compose.ui.platform.LocalContext
import androidx.core.app.ActivityCompat
import androidx.navigation.NavHostController
import com.google.android.gms.location.LocationServices
import com.mapbox.geojson.Point
import com.mapbox.maps.CameraOptions
import com.mapbox.maps.EdgeInsets
import com.mapbox.maps.Style
import com.mapbox.maps.extension.compose.MapboxMap
import com.mapbox.maps.extension.compose.animation.viewport.rememberMapViewportState
import com.mapbox.maps.extension.compose.style.MapStyle

@OptIn(ExperimentalMaterial3Api::class)
@Composable
fun WayfindingSitesView(
    nsdkSessionManager: NSDKSessionManager,
    navHostController: NavHostController,
    helpContentState: MutableState<Any?>
) {
    val context = LocalContext.current

    // Start from a default location until the device location is available.
    var defaultLatLng by remember {
        mutableStateOf(Point.fromLngLat(-122.39360033247367, 37.7955374600894))
    }

    // Keep local UI state for the current map screen.
    var selectedMapStyle by remember { mutableStateOf(WayfindingMapStyleOption.Standard) }

    // Track one shared viewport state for the full-screen map.
    val viewportState = rememberMapViewportState {
        setCameraOptions {
            zoom(12.0)
            pitch(0.0)
            bearing(0.0)
            center(defaultLatLng)
            padding(EdgeInsets(0.0, 0.0, 0.0, 0.0))
        }
    }

    // Recenter the map on the user's current location when it becomes available.
    LaunchedEffect(Unit) {
        fetchLocation(context) { loc ->
            loc?.let {
                defaultLatLng = Point.fromLngLat(it.longitude, it.latitude)
                viewportState.flyTo(
                    CameraOptions.Builder()
                        .center(defaultLatLng)
                        .zoom(12.0)
                        .build()
                )
            }
        }
    }

    Box(modifier = Modifier.fillMaxSize()) {
        MapboxMap(
            modifier = Modifier.fillMaxSize(),
            mapViewportState = viewportState,
            style = { MapStyle(style = selectedMapStyle.styleUri) },
        ) {
            // Later steps add map padding, the location puck, and Site pins here.
        }

        // Later steps add the organization menu, style controls, and site panel here.
    }
}

private fun fetchLocation(context: Context, onResult: (android.location.Location?) -> Unit) {
    val fusedLocationClient = LocationServices.getFusedLocationProviderClient(context)

    if (ActivityCompat.checkSelfPermission(context, Manifest.permission.ACCESS_FINE_LOCATION)
        != PackageManager.PERMISSION_GRANTED) {
        onResult(null)
        return
    }

    fusedLocationClient.lastLocation.addOnSuccessListener { onResult(it) }
}

private enum class WayfindingMapStyleOption(val title: String, val styleUri: String) {
    Standard("Standard", Style.MAPBOX_STREETS),
    Satellite("Satellite", Style.SATELLITE),
    Hybrid("Hybrid", Style.SATELLITE_STREETS)
}
```

### Create an auth retry helper

In an existing app, update your current auth or networking helper layer. If you are unsure how to implement this step, use the following new app example as a reference.

This step should:

- Wait for `NSDKSession` to become authorized before running Sites requests.
- Retry a failed Sites request once after a short delay.
- Keep the retry logic outside `WayfindingSitesManager`.

In a new app, create `app/src/main/java/<your app package path>/auth/AuthRetryHelper.kt` as shown in the following code example:

#### Expand to view AuthRetryHelper.kt

```kotlin
package com.example.wayfinding.auth // Replace with your app package name

import android.util.Log
import com.nianticspatial.nsdk.NSDKSession
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.delay
import kotlinx.coroutines.withContext

class AuthRetryHelper(private val nsdkSession: NSDKSession) {
    companion object {
        private const val TAG = "AuthRetryHelper"
        private const val INITIAL_AUTH_WAIT_MS = 30_000L
        private const val RETRY_DELAY_MS = 1_000L
        private const val AUTH_POLL_INTERVAL_MS = 1_000L
    }

    suspend fun <T> withRetry(operation: suspend () -> T): T {
        waitForAuthorizationIfNeeded(INITIAL_AUTH_WAIT_MS)
        return withContext(Dispatchers.Main) {
            try {
                operation()
            } catch (e: Exception) {
                Log.d(TAG, "Operation failed: ${e.message}, retrying once...")
                delay(RETRY_DELAY_MS)
                operation()
            }
        }
    }

    private suspend fun waitForAuthorizationIfNeeded(timeoutMs: Long) {
        withContext(Dispatchers.Main) {
            if (nsdkSession.isAuthorized) return@withContext

            val startTime = System.currentTimeMillis()
            while (!nsdkSession.isAuthorized) {
                if (System.currentTimeMillis() - startTime > timeoutMs) {
                    throw AuthRetryException("Timeout waiting for authorization")
                }
                delay(AUTH_POLL_INTERVAL_MS)
            }
        }
    }
}

class AuthRetryException(message: String) : Exception(message)
```

In the `vps2e2e` sample, the equivalent implementation lives in `src/main/java/com/nianticspatial/nsdk/vps2e2ekotlin/auth/AuthRetryHelper.kt`.

In a new app, update the Sites manager flow with the following steps:

1. Create `app/src/main/java/<your app package path>/WayfindingSitesManager.kt` as shown in the following code example:

#### Expand to view WayfindingSitesManager.kt

```kotlin
package com.example.wayfinding // Replace with your app package name

import androidx.compose.runtime.getValue
import androidx.compose.runtime.mutableStateOf
import androidx.compose.runtime.setValue
import androidx.lifecycle.DefaultLifecycleObserver
import androidx.lifecycle.LifecycleOwner
import com.example.wayfinding.auth.AuthRetryHelper
import com.nianticspatial.nsdk.LatLng
import com.nianticspatial.nsdk.NSDKSession
import com.nianticspatial.nsdk.sites.AssetDeploymentType
import com.nianticspatial.nsdk.sites.OrganizationInfo
import com.nianticspatial.nsdk.sites.SitesException
import com.nianticspatial.nsdk.sites.SitesSession
import com.nianticspatial.nsdk.sites.UserInfo
import kotlinx.coroutines.CancellationException
import kotlinx.coroutines.CoroutineScope
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.SupervisorJob
import kotlinx.coroutines.async
import kotlinx.coroutines.cancel
import kotlinx.coroutines.coroutineScope
import kotlinx.coroutines.launch

class WayfindingSitesManager(
    private val nsdkSession: NSDKSession,
    private val coroutineScope: CoroutineScope = CoroutineScope(Dispatchers.Main + SupervisorJob()),
) : DefaultLifecycleObserver {
    // Acquire one shared Sites session from the NSDK session.
    private val sitesSession: SitesSession = nsdkSession.sites.acquire()
    private val retryHelper = AuthRetryHelper(nsdkSession)

    // Track the current state of the Sites flow for the map UI.
    var navState by mutableStateOf<SitesNavState>(SitesNavState.Uninitialized)
        private set

    // Keep the current Organizations and current location available for map overlays.
    private var currentUser: UserInfo? = null
    var currentOrganizations: List<OrganizationInfo> = emptyList()
    var currentLocation: LatLng? = null
        private set

    fun loadInitialData() {
        if (navState != SitesNavState.Uninitialized) {
            return
        }

        coroutineScope.launch {
            try {
                navState = SitesNavState.Loading

                val orgsResult = retryHelper.withRetry {
                    sitesSession.requestSelfOrganizationInfo()
                }
                val organizations = orgsResult.organizations
                currentOrganizations = organizations

                val warning = if (organizations.isEmpty()) "No organizations found" else null
                navState = SitesNavState.UserView(null, organizations, warning)

                // Select the first Organization by default so later steps can render Site pins.
                if (organizations.isNotEmpty()) {
                    onOrganizationClick(organizations[0], currentLocation)
                }
            } catch (e: CancellationException) {
                throw e
            } catch (e: SitesException) {
                navState = SitesNavState.Error("Error: ${e.error}")
            } catch (e: Exception) {
                navState = SitesNavState.Error("Error: ${e.message}")
            }
        }
    }

    fun onOrganizationClick(org: OrganizationInfo, location: LatLng?) {
        currentLocation = location
        coroutineScope.launch {
            loadSitesForOrganization(org)
        }
    }

    private suspend fun loadSitesForOrganization(org: OrganizationInfo) {
        try {
            navState = SitesNavState.Loading

            val result = retryHelper.withRetry {
                sitesSession.requestSitesForOrganization(org.id)
            }
            val allSites = result.sites

            if (allSites.isEmpty()) {
                navState = SitesNavState.OrganizationView(
                    org,
                    emptyList(),
                    "No sites found for ${org.name}"
                )
                return
            }

            val sitesWithAssets = coroutineScope {
                allSites.map { site ->
                    async {
                        try {
                            val assetsResult = retryHelper.withRetry {
                                sitesSession.requestAssetsForSite(site.id)
                            }
                            val vpsAsset = assetsResult.assets.firstOrNull { asset ->
                                val vps = asset.vpsData
                                vps != null &&
                                    vps.anchorPayload.isNotBlank() &&
                                    asset.deployment == AssetDeploymentType.PRODUCTION
                            }
                            if (vpsAsset != null) SiteWithVpsAsset(site, vpsAsset) else null
                        } catch (_: Exception) {
                            null
                        }
                    }
                }.mapNotNull { it.await() }
            }

            val warning = if (sitesWithAssets.isEmpty()) {
                "No sites with Production VPS asset found for ${org.name}"
            } else {
                null
            }
            navState = SitesNavState.OrganizationView(org, sitesWithAssets, warning)
        } catch (e: CancellationException) {
            throw e
        } catch (e: SitesException) {
            val user = currentUser
            navState = if (user != null) {
                SitesNavState.UserView(
                    user,
                    currentOrganizations,
                    "Error loading sites: ${e.error}"
                )
            } else {
                SitesNavState.Error("Error loading sites: ${e.error}")
            }
        } catch (e: Exception) {
            val user = currentUser
            navState = if (user != null) {
                SitesNavState.UserView(
                    user,
                    currentOrganizations,
                    "Error: ${e.message}"
                )
            } else {
                SitesNavState.Error("Error: ${e.message}")
            }
        }
    }

    override fun onDestroy(owner: LifecycleOwner) {
        coroutineScope.cancel()
        runCatching { sitesSession.close() }
    }
}
```

```swift
import SwiftUI
import MapKit
import NSDK

struct WayfindingSitesView: View {
    // Reuse the shared session that the landing flow already created.
    let nsdkSession: NSDKSession
    // Continue into the placeholder VPS2 route from the previous page.
    let onNavigateToVPS2: (_ siteName: String, _ payload: String, _ nsdkSession: NSDKSession) -> Void

    // Start at the user location and fall back to a default region until the map has Site data.
    @State private var cameraPosition = MapCameraPosition.userLocation(
        fallback: .region(WayfindingSitesDefaultRegion)
    )
    // Keep local map style state in the view.
    @State private var selectedMapStyle: WayfindingMapStyleOption = .standard

    var body: some View {
        ZStack {
            // Start with only the base map. Later steps add overlays and the selected-Site panel.
            mapLayer
            // Later sections add the Organization menu, loading overlay, and selected-Site panel here.
        }
        .navigationTitle("Browse Sites")
        .navigationBarTitleDisplayMode(.inline)
    }

    private var mapLayer: some View {
        // Show the user location immediately, even before Site data is loaded.
        Map(position: $cameraPosition) {
            UserAnnotation()
        }
        .mapStyle(selectedMapStyle.mapStyle)
        .ignoresSafeArea()
    }
}

private let WayfindingSitesDefaultRegion = MKCoordinateRegion(
    center: CLLocationCoordinate2D(
        latitude: 37.7955374600894,
        longitude: -122.39360033247367
    ),
    span: MKCoordinateSpan(latitudeDelta: 0.08, longitudeDelta: 0.08)
)

private enum WayfindingMapStyleOption: CaseIterable, Identifiable {
    case standard
    case imagery
    case hybrid

    var id: String { title }

    var title: String {
        switch self {
        case .standard:
            return "Standard"
        case .imagery:
            return "Satellite"
        case .hybrid:
            return "Hybrid"
        }
    }

    var mapStyle: MapStyle {
        switch self {
        case .standard:
            return .standard
        case .imagery:
            return .imagery
        case .hybrid:
            return .hybrid
        }
    }
}
```

```swift
    case loading(WayfindingSitesLoadingContext)
    case userView(organizations: [OrganizationInfo], warning: String? = nil)
    case organizationView(
        organization: OrganizationInfo,
        sites: [WayfindingSiteAnnotationData],
        warning: String? = nil
    )
    case error(message: String)
}

// Map SDK and network failures into one error type the SwiftUI view can render.
enum WayfindingSitesError: Error {
    case missingCredentials
    case authorizationRequired
    case authorizationTimeout
    case networkError
    case httpForbidden
    case httpNotFound
    case httpTooManyRequests
    case httpServerError
    case sdkError(code: String, message: String)
    case unknown(message: String)

    var code: String {
        switch self {
        case .missingCredentials:
            return "MISSING_CREDENTIALS"
        case .authorizationRequired:
            return "AUTH_REQUIRED"
        case .authorizationTimeout:
            return "AUTH_TIMEOUT"
        case .networkError:
            return "NETWORK_ERROR"
        case .httpForbidden:
            return "HTTP_FORBIDDEN"
        case .httpNotFound:
            return "HTTP_NOT_FOUND"
        case .httpTooManyRequests:
            return "HTTP_TOO_MANY_REQUESTS"
        case .httpServerError:
            return "HTTP_SERVER_ERROR"
        case .sdkError(let code, _):
            return code
        case .unknown:
            return "UNKNOWN_ERROR"
        }
    }

    var message: String {
        switch self {
        case .missingCredentials:
            return "Authentication is required. Please sign in."
        case .authorizationRequired:
            return "Authorization is not ready. Please retry."
        case .authorizationTimeout:
            return "Authorization timed out. Please retry."
        case .networkError:
            return "A network or authentication error occurred. Please try again."
        case .httpForbidden:
            return "Access was forbidden. Please check your credentials."
        case .httpNotFound:
            return "The requested resource was not found."
        case .httpTooManyRequests:
            return "Too many requests. Please wait a moment and try again."
        case .httpServerError:
            return "A server error occurred. Please try again later."
        case .sdkError(_, let message):
            return message
        case .unknown(let message):
            return message
        }
    }

    var displayText: String {
        "[\(code)] \(message)"
    }

    static func from(_ error: Error) -> WayfindingSitesError {
        if let sitesError = error as? WayfindingSitesError {
            return sitesError
        }

        if let authRetryError = error as? AuthRetryError {
            switch authRetryError {
            case .authorizationTimeout:
                return .authorizationTimeout
            }
        }

        if let nsdkError = error as? NSDKError, nsdkError == .invalidOperation {
            return .authorizationRequired
        }

        if let sitesResultError = error as? SitesResult.Error {
            switch sitesResultError {
            case .networkError:
                return .networkError
            case .httpForbidden:
                return .httpForbidden
            case .httpNotFound:
                return .httpNotFound
            case .httpTooManyRequests:
                return .httpTooManyRequests
            case .httpServerError:
                return .httpServerError
            case .invalidRequest:
                return .sdkError(
                    code: "INVALID_REQUEST",
                    message: "The request was invalid."
                )
            case .parseError:
                return .sdkError(
                    code: "PARSE_ERROR",
                    message: "Failed to parse the server response."
                )
            case .unexpectedError:
                return .sdkError(
                    code: "UNEXPECTED_ERROR",
                    message: "An unexpected error occurred."
                )
            case .none:
                return .sdkError(
                    code: "SDK_NO_ERROR",
                    message: "No error reported."
                )
            }
        }

        let nsError = error as NSError
        if !nsError.localizedDescription.isEmpty {
            return .unknown(message: nsError.localizedDescription)
        }

        return .unknown(message: "Unexpected error occurred.")
    }
}
```

### Create an auth retry helper

In an existing app, update your current auth or networking helper layer so Sites requests can wait for authorization and retry once on failure. If you are unsure how to implement this step, use the following new app example as a reference.

This step should:

- Wait for `NSDKSession` to become authorized before running Sites requests.
- Retry a failed Sites request once after a short delay.
- Keep the retry logic outside `WayfindingSitesManager`.

In a new app, create `Auth/AuthRetryHelper.swift` with the following contents:

#### Expand to view AuthRetryHelper.swift

```swift
import Foundation
import NSDK

@MainActor
final class AuthRetryHelper {
    private let session: NSDKSession
    private let initialAuthWaitSeconds: TimeInterval = 30.0
    private let retryDelaySeconds: TimeInterval = 1.0

    init(session: NSDKSession) {
        self.session = session
    }

    func withRetry<T>(_ operation: () async throws -> T) async throws -> T {
        // Wait for the session to become authorized before running Sites requests.
        try await waitForAuthorizationIfNeeded(timeout: initialAuthWaitSeconds)
        do {
            return try await operation()
        } catch {
            // Retry one transient failure after a short delay.
            print("[AuthRetryHelper] Operation failed: \(error), retrying once...")
            try await Task.sleep(
                nanoseconds: UInt64(retryDelaySeconds * 1_000_000_000)
            )
            return try await operation()
        }
    }

    private func waitForAuthorizationIfNeeded(timeout: TimeInterval) async throws {
        guard !session.isAuthorized else { return }

        // Poll until authorization is ready or the timeout is reached.
        let startTime = Date()
        while !session.isAuthorized {
            try Task.checkCancellation()
            if Date().timeIntervalSince(startTime) > timeout {
                throw AuthRetryError.authorizationTimeout
            }
            try await Task.sleep(nanoseconds: 1_000_000_000)
        }
    }
}

enum AuthRetryError: Error, LocalizedError {
    case authorizationTimeout

    var errorDescription: String? {
        switch self {
        case .authorizationTimeout:
            return "Timeout waiting for NSDK session authorization"
        }
    }
}
```

   ```swift
   import Foundation
   import NSDK

   // Keep the NSDK Sites calls out of the SwiftUI view and manager state transitions.
   @MainActor
   protocol WayfindingSitesServiceProtocol {
       func fetchOrganizations() async throws -> [OrganizationInfo]
       func fetchSites(for organizationId: String) async throws -> [SiteInfo]
       func fetchAssets(for siteId: String) async throws -> [AssetInfo]
   }

   @MainActor
   final class WayfindingSitesService: WayfindingSitesServiceProtocol {
       private let sitesSession: NSDKSitesSession
       private let retryHelper: AuthRetryHelper

       init(nsdkSession: NSDKSession, retryHelper: AuthRetryHelper) {
           self.sitesSession = nsdkSession.acquireSitesSession()
           self.retryHelper = retryHelper
       }

       func fetchOrganizations() async throws -> [OrganizationInfo] {
           // Load the Organizations available to the current access token from the Sites session.
           let orgResult = try await retryHelper.withRetry {
               try await self.sitesSession.requestSelfOrganizationInfo()
           }

           return orgResult.organizations
       }

       func fetchSites(for organizationId: String) async throws -> [SiteInfo] {
           // Load all Sites for the selected Organization.
           let siteResult = try await retryHelper.withRetry {
               try await self.sitesSession.requestSitesForOrganization(orgId: organizationId)
           }

           return siteResult.sites
       }

       func fetchAssets(for siteId: String) async throws -> [AssetInfo] {
           // Load the assets needed to determine whether the Site supports VPS2 navigation.
           let assetResult = try await retryHelper.withRetry {
               try await self.sitesSession.requestAssetsForSite(siteId: siteId)
           }

           return assetResult.assets
       }
   }
   ```

2. Create `Sites/WayfindingSitesManager.swift` to load Organizations, filter VPS-ready Sites, and track the selected Site:

   #### Expand to view WayfindingSitesManager.swift

   ```swift
   import Foundation
   import Observation
   import NSDK

   @Observable
   @MainActor
   final class WayfindingSitesManager {
       enum RetryScope {
           case organizations
           case sites
       }

       private let sitesService: WayfindingSitesServiceProtocol
       private var retryScope: RetryScope = .organizations
       private var loadTask: Task<Void, Never>?

       private(set) var navState: WayfindingSitesNavState = .uninitialized
       private(set) var currentOrganizations: [OrganizationInfo] = []
       private(set) var selectedOrganization: OrganizationInfo?
       private(set) var selectedSite: WayfindingSiteAnnotationData?

       init(sitesService: WayfindingSitesServiceProtocol) {
           self.sitesService = sitesService
       }

       var sites: [WayfindingSiteAnnotationData] {
           switch navState {
           case .organizationView(_, let sites, _):
               return sites
           default:
               return []
           }
       }

       func loadInitialData() {
           // Avoid starting another request while the current one is still loading.
           if case .loading = navState { return }

           retryScope = .organizations
           navState = .loading(.organizations)
           loadTask?.cancel()

           loadTask = Task { @MainActor in
               do {
                   // Load Organizations first, then pick the first one as the initial map context.
                   let organizations = try await sitesService.fetchOrganizations()
                   currentOrganizations = organizations
                   print("Loaded \(organizations.count) organizations")

                   guard let firstOrganization = organizations.first else {
                       selectedOrganization = nil
                       selectedSite = nil
                       navState = .userView(
                           organizations: organizations,
                           warning: "No organizations available"
                       )
                       return
                   }

                   selectedOrganization = firstOrganization
                   try await performSiteLoad(
                       for: firstOrganization,
                       using: sitesService
                   )
               } catch is CancellationError {
                   return
               } catch {
                   navState = .error(
                       message: WayfindingSitesError.from(error).displayText
                   )
               }
           }
       }

       func selectOrganization(_ organization: OrganizationInfo) {
           // Skip redundant reloads when the user taps the current Organization.
           guard selectedOrganization?.id != organization.id else { return }
           selectedOrganization = organization
           loadSites(for: organization)
       }

       func selectSite(_ site: WayfindingSiteAnnotationData) {
           // Save the selected Site so the panel and camera can react to it.
           selectedSite = site
           print("Selected Site pin: \(site.siteName)")
       }

       func clearSelectedSite() {
           selectedSite = nil
       }

       func retry() {
           // Retry the failed phase instead of always reloading everything from scratch.
           switch retryScope {
           case .organizations:
               loadInitialData()
           case .sites:
               guard let selectedOrganization else {
                   loadInitialData()
                   return
               }
               loadSites(for: selectedOrganization)
           }
       }

       private func loadSites(for organization: OrganizationInfo) {
           loadTask?.cancel()
           loadTask = Task { @MainActor in
               do {
                   // Reload the filtered Site list for the selected Organization.
                   try await performSiteLoad(
                       for: organization,
                       using: sitesService
                   )
               } catch is CancellationError {
                   return
               } catch {
                   navState = .error(
                       message: WayfindingSitesError.from(error).displayText
                   )
               }
           }
       }

       private func performSiteLoad(
           for organization: OrganizationInfo,
           using service: WayfindingSitesServiceProtocol
       ) async throws {
           retryScope = .sites
           selectedOrganization = organization
           selectedSite = nil
           navState = .loading(.sites(organizationName: organization.name))

           // Load and filter the Sites before the map tries to render them.
           let annotations = try await fetchAnnotations(
               for: organization,
               using: service
           )

           print("Loaded \(annotations.count) VPS-ready Sites for \(organization.name)")

           if annotations.isEmpty {
               navState = .organizationView(
                   organization: organization,
                   sites: [],
                   warning: "No Sites with Production VPS asset found for \(organization.name)"
               )
           } else {
               navState = .organizationView(
                   organization: organization,
                   sites: annotations,
                   warning: nil
               )
           }
       }

       private func fetchAnnotations(
           for organization: OrganizationInfo,
           using service: WayfindingSitesServiceProtocol
       ) async throws -> [WayfindingSiteAnnotationData] {
           // Only Sites with coordinates can appear on the map.
           let allSites = try await service.fetchSites(for: organization.id)
           let locatedSites = allSites.filter { $0.location != nil }

           guard !locatedSites.isEmpty else {
               return []
           }

           return try await buildAnnotations(
               from: locatedSites,
               using: service
           )
       }

       private func buildAnnotations(
           from sites: [SiteInfo],
           using service: WayfindingSitesServiceProtocol
       ) async throws -> [WayfindingSiteAnnotationData] {
           var annotations: [WayfindingSiteAnnotationData] = []

           try await withThrowingTaskGroup(of: WayfindingSiteAnnotationData?.self) { group in
               for site in sites {
                   group.addTask {
                       try Task.checkCancellation()
                       guard let coordinate = site.location else { return nil }

                       // Keep only Production VPS payloads that can launch the next step.
                       let assets = try await service.fetchAssets(for: site.id)
                       let productionPayload = assets.first { asset in
                           asset.deployment == .production && asset.vpsData != nil
                       }?.vpsData?.anchorPayload ?? ""

                       guard !productionPayload.isEmpty else {
                           return nil
                       }

                       let vpsAssetVersionCount = assets.filter { $0.vpsData != nil }.count
                       let scanCount = Set(assets.flatMap(\.sourceScanIds)).count

                       return WayfindingSiteAnnotationData(
                           id: site.id,
                           siteName: site.name,
                           canNavigate: true,
                           scanCount: scanCount,
                           vpsAssetVersionCount: vpsAssetVersionCount,
                           coordinate: coordinate,
                           payload: productionPayload
                       )
                   }
               }

               for try await annotation in group {
                   if let annotation {
                       annotations.append(annotation)
                   }
               }
           }

           try Task.checkCancellation()

           return annotations.sorted {
               $0.siteName.localizedCaseInsensitiveCompare($1.siteName) == .orderedAscending
           }
       }
   }
   ```

```swift
    if let newId, let site = sitesManager.sites.first(where: { $0.id == newId }) {
        withAnimation(.easeInOut(duration: 0.25)) {
            // Save the selection and recenter the map on the Site the user tapped.
            sitesManager.selectSite(site)
            cameraPosition = .camera(
                MapCamera(centerCoordinate: site.coordinate, distance: 500)
            )
        }
    } else {
        withAnimation(.easeInOut(duration: 0.25)) {
            // Clear the selected Site when the user dismisses the marker selection.
            sitesManager.clearSelectedSite()
        }
    }
}
```
