# Initialize the wayfinding app

Source: https://www.nianticspatial.com/docs/nsdk/vps2e2e/vps2-e2e-landing-page/

This guide is the second part of a five-part series on creating a wayfinding experience to help a user understand where they are, choose a destination, localize to that location, and follow AR guidance in the space. The first section to [set up the project](https://www.nianticspatial.com/docs/nsdk/vps2e2e/vps2-e2e-getting-started/) shows how to configure an existing project to add and embed the Niantic Software Development Kit (NSDK).

This section shows you how to initialize a wayfinding app's entry flow. Specifically, this part of the guide shows you how to:

- [Create the app entry point](#create-the-app-entry-point) - set the wayfinding app as the root UI, create a listener to deliver frames to the NSDK, and create long-lived session managers and objects.
- [Present authorization](#present-authorization) - add sign-in state and display authorization UI when needed.
- [Request permissions](#request-permissions) - check and request required camera and location permissions.
- [Route to Sites flow](#route-to-sites-flow) - define navigation that moves the user from the entry screen into the Sites screen.

### Platform: kotlin

## Files overview

The app entry flow in the initialization step has five responsibilities:

1. Create the app entry point.
2. Present authorization.
3. Request permissions.
4. Route to Sites flow.
5. Select a Site and return payload.

Your app can organize those responsibilities in different files. The following table shows one way to structure them in a standalone app shown in this tutorial, along with the names of the matching files in the public `vps2e2e` sample app with the corresponding functionalities.

| Responsibility | Standalone app | Sample reference |
|------|------|------|
| Create the app entry point | `MainActivity.kt`, `OnFrameUpdateListener.kt`, `ARSessionManager.kt`, `NSDKSessionManager.kt`, and `WayfindingApp.kt` create the root UI and shared NSDK session objects | `MainActivity.kt`, `LandingView.kt`, `ARSessionManager.kt`, and `NSDKSessionManager.kt` |
| Present authorization | `auth/WayfindingAuthManager.kt`, `auth/WayfindingAuthView.kt`, and `WayfindingApp.kt` present auth state and auth UI | `LandingView.kt`, `auth/AuthManager.kt`, and `auth/AuthView.kt` |
| Request permissions | `permissions/PermissionHelper.kt` and `WayfindingApp.kt` gate the flow on required camera and location permissions | `MainActivity.kt`, `LandingView.kt`, and `common/PermissionsView.kt` |
| Route to Sites flow | `WayfindingApp.kt` defines the top-level navigation and opens the Sites screen after auth and permissions are ready | `MainActivity.kt`, `LandingView.kt`, and `SitesRoute.kt` |
| Select a Site and return payload | `WayfindingApp.kt` receives the selected payload from the Sites screen and passes it into the `vps2` route | `LandingView.kt`, `SitesRoute.kt`, and `VPS2Route.kt` |

## Create the app entry point

To create the shared-session part of the app entry flow, set up the app entry point so it initializes the shared NSDK session and managers once. Later steps in this tutorial reuse those objects when they add authentication, permissions, and the Sites flow.

There are five steps to create an app entry point, shown in detail in the following sections:

1. [Set the root UI](#set-the-root-ui) for your wayfinding app.
2. [Create a listener](#create-a-listener) to send frames to the NSDK.
3. [Create an AR session manager](#create-an-ar-session-manager) helper to track playback and forward frames to listeners to update the NSDK.
4. [Create an NSDK session manager](#create-an-nsdk-session-manager) to forward frames to the NSDK.
5. [Create a wayfinding app](#create-a-wayfinding-app) in a top-level compossable that integrates the session and managers into an app.

The examples in this tutorial can use either live AR or a playback dataset. For a normal on-device walkthrough, leave playback disabled and use live AR. If you want to test playback mode, download the sample dataset [`gandhi_statue.tgz`](https://storage.googleapis.com/nianticweb-epos-web-staging/gandhi_statue.tgz), extract it, and copy the extracted folder into `app/src/main/assets/playback/gandhi_statue/` so the folder contains `capture.json`.

Use the following steps to create or update your app entry point:

### Set the root UI

In an existing app, update the file that currently calls `setContent` so it shows `WayfindingApp()` as the root UI for this feature. If you are unsure how to implement this step, use the following new app example as a reference.

This step should:

- Show `WayfindingApp()` as the root composable.
- Keep the activity as the entry point for the wayfinding flow.
- Replace the default Android Studio template UI.

In a new app, update `app/src/main/java/<your app package path>/MainActivity.kt` to update `MainActivity.kt` so the activity launches `WayfindingApp()` as the root composable:

```kotlin
package com.example.wayfinding // Replace with your app package name
class MainActivity : ComponentActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContent {
            WayfindingTheme {
                // Start the wayfinding flow from a single top-level composable
                WayfindingApp(activity = this)
            }
        }
    }
}
```

### Create a listener

In an existing app, add a small listener interface that both live AR and playback can use to deliver frames into NSDK. If you are unsure how to implement this step, use the following new app example as a reference.

The listener should:

- Accept one prepared frame at a time.
- Work for both live ARCore frames and playback frames.
- Give the rest of the app one shared callback type for NSDK updates.

In a new app, create `app/src/main/java/<your app package path>/OnFrameUpdateListener.kt` to define a shared callback interface for both live ARCore frames and playback frames:

```kotlin
package com.example.wayfinding // Replace with your app package name

import com.nianticspatial.nsdk.NsdkFrame

// Forward one prepared frame at a time into the rest of the app
fun interface OnFrameUpdateListener {
    fun onFrameUpdate(frame: NsdkFrame)
}
```

This listener gives the app one shared callback type for both live ARCore frames and playback frames.

### Create an AR session manager

In an existing app, update your current AR session owner or create a helper file in the same package as your AR code. If you are unsure how to implement this step, use the following new app example as a reference.

The AR session manager should:

- Track whether the app is using live AR or playback.
- Load a playback dataset only when one is configured.
- Forward each frame to any listeners that need to update NSDK.

In a new app, create `app/src/main/java/<your app package path>/ARSessionManager.kt` to optionally load a playback dataset, track device orientation, and forward live or playback frames to the rest of the app:

#### Expand to view `ARSessionManager.kt`

```kotlin
package com.example.wayfinding // Replace with your app package name

import android.app.Activity
import android.hardware.display.DisplayManager
import android.view.Display
import android.view.Surface
import androidx.compose.runtime.getValue
import androidx.compose.runtime.mutableStateOf
import androidx.compose.runtime.setValue
import androidx.lifecycle.DefaultLifecycleObserver
import androidx.lifecycle.LifecycleOwner
import com.google.ar.core.Frame
import com.google.ar.core.Session
import com.nianticspatial.nsdk.NsdkFrame
import com.nianticspatial.nsdk.Orientation
import com.nianticspatial.nsdk.playback.AssetPlaybackDatasetLoader
import com.nianticspatial.nsdk.playback.PlaybackDataset
import com.nianticspatial.nsdk.playback.PlaybackFrame
import com.nianticspatial.nsdk.playback.PlaybackSession
import kotlinx.coroutines.CoroutineScope
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.SupervisorJob
import kotlinx.coroutines.cancel
import kotlinx.coroutines.launch
import kotlinx.coroutines.withContext

enum class SessionMode { LIVE, PLAYBACK }

class ARSessionManager(
    private val activity: Activity,
    playbackDatasetPath: String = ""
) : DefaultLifecycleObserver {
    // Track whether the AR flow is currently active.
    var active: Boolean by mutableStateOf(false)
        private set

    // Track whether the app is using live AR or playback.
    var mode: SessionMode by mutableStateOf(SessionMode.LIVE)
        private set

     private var playbackSession: PlaybackSession? = null

    // Track whether a configured playback dataset is still loading.
    var isPlaybackLoading: Boolean by mutableStateOf(false)
        private set

    var depthAvailability: Boolean by mutableStateOf(false)
        private set

    var deviceOrientation: Orientation by mutableStateOf(Orientation.PORTRAIT)
        private set

    var currentLiveFrame: Frame? = null
        private set

    var currentPlaybackFrame: PlaybackFrame? by mutableStateOf(null)
        private set

    // Expose whichever frame source is active so downstream code can stay mode-agnostic.
    val currentFrame: NsdkFrame?
        get() = when (mode) {
            SessionMode.PLAYBACK -> currentPlaybackFrame?.let { NsdkFrame.Playback(it) }
            SessionMode.LIVE -> currentLiveFrame?.let { NsdkFrame.Live(it) }
        }

    // Register the listeners that need every frame in order to update NSDK.
    private val frameUpdateListeners = mutableListOf<OnFrameUpdateListener>()

    fun addFrameUpdateListener(listener: OnFrameUpdateListener) {
        frameUpdateListeners.add(listener)
    }

    fun removeFrameUpdateListener(listener: OnFrameUpdateListener) {
        frameUpdateListeners.remove(listener)
    }

    private val playbackScope = CoroutineScope(SupervisorJob() + Dispatchers.Default)

    private val displayListener = object : DisplayManager.DisplayListener {
        override fun onDisplayChanged(displayId: Int) { updateDisplayRotation() }
        override fun onDisplayAdded(displayId: Int) {}
        override fun onDisplayRemoved(displayId: Int) {}
    }

    init {
        // Track device orientation so NSDK can consume the correct screen rotation.
        val displayManager = activity.getSystemService(Activity.DISPLAY_SERVICE) as DisplayManager
        displayManager.registerDisplayListener(displayListener, null)
        updateDisplayRotation()

        // Load a playback dataset only when one is configured.
        if (playbackDatasetPath.isNotEmpty()) {
            mode = SessionMode.PLAYBACK
            android.util.Log.i("WayfindingApp", "ARSessionManager using playback mode")
            isPlaybackLoading = true
            val path = playbackDatasetPath
            val act = activity
            playbackScope.launch {
                val dataset = AssetPlaybackDatasetLoader(act, path).loadDataset()
                withContext(Dispatchers.Main.immediate) {
                    if (!act.isFinishing && !act.isDestroyed && dataset != null) {
                        setPlaybackDataset(dataset)
                    } else {
                        mode = SessionMode.LIVE
                        android.util.Log.i("WayfindingApp", "ARSessionManager falling back to live AR mode")
                    }
                    isPlaybackLoading = false
                }
            }
        } else {
            android.util.Log.i("WayfindingApp", "ARSessionManager using live AR mode")
        }
    }

    fun updateFrame(frame: Frame) {
        synchronized(this) {
            currentLiveFrame = frame
        }
        // Forward each live frame to listeners that will update NSDK.
        if (active) {
            frameUpdateListeners.forEach { it.onFrameUpdate(NsdkFrame.Live(frame)) }
        }
    }

    fun setEnabled(value: Boolean) {
        val wasActive = active
        active = value
        // Start or pause playback when the AR screen becomes active or inactive.
        if (wasActive != value && mode == SessionMode.PLAYBACK) {
            if (value) {
                playbackSession?.seekToStart()
                playbackSession?.play()
            } else {
                playbackSession?.pause()
            }
        }
    }

    private fun setPlaybackDataset(dataset: PlaybackDataset?) {
        // Reset the current playback state before switching datasets or returning to live AR.
        playbackSession?.dispose()
        playbackSession = null
        currentPlaybackFrame = null

        if (dataset == null) {
            mode = SessionMode.LIVE
            depthAvailability = false
            return
        }

        mode = SessionMode.PLAYBACK
        depthAvailability = dataset.hasDepth()

        // Create the playback session and route each playback frame through the same listener path.
        playbackSession = PlaybackSession(dataset)
        playbackSession?.setOnFrameListener { frame ->
            playbackScope.launch {
                withContext(Dispatchers.Main.immediate) {
                    currentPlaybackFrame = frame
                    // Forward each playback frame to listeners that will update NSDK.
                    if (active) {
                        frameUpdateListeners.forEach { it.onFrameUpdate(NsdkFrame.Playback(frame)) }
                    }
                }
            }
        }

        if (active) {
            playbackSession?.seekToStart()
            playbackSession?.play()
        }
    }

    fun setSession(arSession: Session) {
        // Keep this method so ARSceneView can hand the live ARCore session to this manager
    }

    private fun updateDisplayRotation() {
        // Convert the current display rotation into the NSDK orientation enum.
        val display: Display = activity.windowManager.defaultDisplay
        deviceOrientation = when (display.rotation) {
            Surface.ROTATION_0 -> Orientation.PORTRAIT
            Surface.ROTATION_90 -> Orientation.LANDSCAPE_LEFT
            Surface.ROTATION_180 -> Orientation.PORTRAIT_UPSIDE_DOWN
            Surface.ROTATION_270 -> Orientation.LANDSCAPE_RIGHT
            else -> Orientation.PORTRAIT
        }
    }

    override fun onDestroy(owner: LifecycleOwner) {
        // Clean up the display listener and playback resources when the host is destroyed.
        val displayManager = activity.getSystemService(Activity.DISPLAY_SERVICE) as DisplayManager
        displayManager.unregisterDisplayListener(displayListener)
        playbackSession?.dispose()
        playbackScope.cancel()
    }
}
```

The code in this step contains the minimal helper needed for this tutorial. In the `vps2e2e` sample, the fuller implementation appears in `src/main/java/com/nianticspatial/nsdk/vps2e2ekotlin/ARSessionManager.kt`.

### Create an NSDK session manager

In an existing app, update your current NSDK bridge or create a helper file in the same package as your session code. If you are unsure how to implement this step, use the following new app example as a reference.

The NSDK session manager should:

- Receive frames from `ARSessionManager`.
- Choose the correct live or playback data source.
- Call `NSDKSession.update()` off the main thread.

In a new app, create `app/src/main/java/<your app package path>/NSDKSessionManager.kt` to receive frames from `ARSessionManager`, choose the right live or playback data source, and call `NSDKSession.update()` off the main thread:

#### Working example: NSDKSessionManager.kt

The following code example creates an `NSDKSessionManager` that chooses the right live or playback data source and updates NSDK on a background thread:

```kotlin
package com.example.wayfinding // Replace with your app package name

import android.content.Context
import android.util.Log
import androidx.lifecycle.DefaultLifecycleObserver
import androidx.lifecycle.LifecycleOwner
import com.nianticspatial.nsdk.NSDKSession
import com.nianticspatial.nsdk.NsdkFrame
import com.nianticspatial.nsdk.NsdkSessionDataSource
import com.nianticspatial.nsdk.Orientation
import com.nianticspatial.nsdk.helpers.createLiveDataSource
import com.nianticspatial.nsdk.helpers.createPlaybackDataSource
import java.util.concurrent.Executors
import java.util.concurrent.TimeUnit
import java.util.concurrent.atomic.AtomicBoolean
import kotlinx.coroutines.CoroutineScope
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.SupervisorJob
import kotlinx.coroutines.asCoroutineDispatcher
import kotlinx.coroutines.cancel
import kotlinx.coroutines.launch
import kotlinx.coroutines.withContext

class NSDKSessionManager(
    context: Context,
    val session: NSDKSession,
    val arManager: ARSessionManager
) : DefaultLifecycleObserver, OnFrameUpdateListener {

    companion object {
        private const val TAG = "NSDKSessionManager"
    }

    private val scope = CoroutineScope(SupervisorJob() + Dispatchers.Main.immediate)
    private val updateExecutor = Executors.newSingleThreadExecutor { runnable ->
        Thread(runnable, "NSDK-Frame-Update").apply { isDaemon = true }
    }
    private val updateDispatcher = updateExecutor.asCoroutineDispatcher()
    private val updateInFlight = AtomicBoolean(false)

    // Build one data source for live AR and one for playback
    private val liveDataSource: NsdkSessionDataSource by lazy {
        createLiveDataSource(
            context = context,
            frameProvider = { arManager.currentLiveFrame },
            orientationProvider = { arManager.deviceOrientation }
        )
    }

    private val playbackDataSource: NsdkSessionDataSource by lazy {
        createPlaybackDataSource(
            frameProvider = { arManager.currentPlaybackFrame },
            orientationProvider = { arManager.deviceOrientation }
        )
    }

    private var activeMode: SessionMode? = null

    val currentFrame: NsdkFrame?
        get() = arManager.currentFrame

    val currentImageOrientation: Orientation
        get() = arManager.deviceOrientation

    init {
        // Listen for frames as soon as the bridge is created
        arManager.addFrameUpdateListener(this)
    }

    override fun onFrameUpdate(frame: NsdkFrame) {
        if (!updateInFlight.compareAndSet(false, true)) return

        val mode = arManager.mode
        val dataSource = when (mode) {
            SessionMode.LIVE -> liveDataSource
            SessionMode.PLAYBACK -> playbackDataSource
        }

        // Swap the session data source only when the session mode changes
        if (activeMode != mode) {
            session.dataSource = dataSource
            activeMode = mode
        }

        scope.launch {
            try {
                val prepared = dataSource.prepareFrame()
                if (prepared) {
                    withContext(updateDispatcher) {
                        session.update()
                    }
                }
            } catch (e: Throwable) {
                Log.w(TAG, "Frame update failed", e)
            } finally {
                updateInFlight.set(false)
            }
        }
    }

    override fun onResume(owner: LifecycleOwner) {
        (liveDataSource as? DefaultLifecycleObserver)?.onResume(owner)
    }

    override fun onPause(owner: LifecycleOwner) {
        (liveDataSource as? DefaultLifecycleObserver)?.onPause(owner)
    }

    override fun onDestroy(owner: LifecycleOwner) {
        arManager.removeFrameUpdateListener(this)
        scope.cancel()
        updateExecutor.shutdown()
        updateExecutor.awaitTermination(5, TimeUnit.SECONDS)
        (liveDataSource as? DefaultLifecycleObserver)?.onDestroy(owner)
        (playbackDataSource as? DefaultLifecycleObserver)?.onDestroy(owner)
    }
}
```

### Create a wayfinding app

In an existing app, add the following logic to the root composable for your wayfinding flow. If you are unsure how to implement this step, use the following new app example as a reference.

The top-level composable should:

- Create and register one shared `ARSessionManager`.
- Wait for playback loading to finish.
- Create one shared `NSDKSession`.
- Create and register one shared `NSDKSessionManager`.
- Render a temporary placeholder screen until later pages add authentication, Sites, and AR navigation.

You will need a token that the NSDK can use for the `NSDKSession` created in this step. For testing this standalone walkthrough, the simplest option is a developer token. For production apps, use backend-issued access tokens. See [Generate developer tokens](https://www.nianticspatial.com/docs/nsdk/auth_developer_token/) and [Generate access tokens](https://www.nianticspatial.com/docs/nsdk/auth_backend/).

In a new app, create `app/src/main/java/<your app package path>/WayfindingApp.kt` as follows:

#### Expand to view `WayfindingApp.kt`

```kotlin
package com.example.wayfinding // Replace with your app package name

import android.app.Activity
import android.util.Log
import androidx.compose.foundation.layout.Box
import androidx.compose.foundation.layout.fillMaxSize
import androidx.compose.material3.Text
import androidx.compose.runtime.Composable
import androidx.compose.runtime.DisposableEffect
import androidx.compose.runtime.remember
import androidx.compose.ui.Alignment
import androidx.compose.ui.Modifier
import androidx.lifecycle.compose.LocalLifecycleOwner
import com.nianticspatial.nsdk.NSDKSession

private const val TAG = "WayfindingApp"
// Leave this empty to use live AR mode.
// Set a playback dataset path only if you want to test playback mode.
private const val PLAYBACK_DATASET_PATH = ""
private const val ACCESS_TOKEN = "REPLACE_WITH_YOUR_ACCESS_TOKEN"

@Composable
fun WayfindingApp(activity: Activity) {
    // Read lifecycle events from the current composable host so helper objects can
    // start and stop cleanly with the screen
    val lifecycleOwner = LocalLifecycleOwner.current

    // Create one shared AR session manager for the whole wayfinding flow
    // This object owns live ARCore state or playback state for the screen
    val sessionManager = remember {
        ARSessionManager(
            activity = activity,
         playbackDatasetPath = PLAYBACK_DATASET_PATH
        ).also {
            Log.i(TAG, "ARSessionManager created")
        }
    }

    // Keep the AR session manager in sync with the composable lifecycle so
    // it can register listeners and clean up correctly
    DisposableEffect(lifecycleOwner, sessionManager) {
        lifecycleOwner.lifecycle.addObserver(sessionManager)
        onDispose {
            lifecycleOwner.lifecycle.removeObserver(sessionManager)
        }
    }

    // Stop here until the playback dataset finishes loading in the background
    // This prevents the app from creating NSDK objects before playback is ready
    val isPlaybackLoading = sessionManager.isPlaybackLoading
    if (isPlaybackLoading) return

    // Match NSDK depth behavior to the current live or playback dataset, then
    // create one shared NSDK session for the rest of the app to reuse
    val depthAvailability = sessionManager.depthAvailability
    val nsdkSession = remember(depthAvailability) {
        NSDKSession(
            accessToken = ACCESS_TOKEN,
            useLidar = depthAvailability
        ).also {
            Log.i(TAG, "NSDKSession created")
        }
    }

    // Forward frames from the AR session manager into NSDK through one shared bridge
    // This is the object that prepares frames and calls NSDKSession.update()
    val nsdkSessionManager = remember(nsdkSession, sessionManager) {
        NSDKSessionManager(activity, nsdkSession, sessionManager).also {
            Log.i(TAG, "NSDKSessionManager created")
        }
    }

    // Register the bridge for cleanup when the composable leaves the screen
    DisposableEffect(lifecycleOwner, nsdkSessionManager) {
        lifecycleOwner.lifecycle.addObserver(nsdkSessionManager)
        onDispose {
            lifecycleOwner.lifecycle.removeObserver(nsdkSessionManager)
        }
    }
    // Show a simple placeholder while later pages add the Sites flow and AR screens
    Box(
        modifier = Modifier.fillMaxSize(),
        contentAlignment = Alignment.Center
    ) {
        Text("Wayfinding app initialized")
    }
}
```

If `LocalLifecycleOwner` is unresolved in your project, add `implementation("androidx.lifecycle:lifecycle-runtime-compose:2.10.0")` to your app module dependencies before continuing.

The previous `WayfindingApp.kt` uses placeholders for UI with the Sites flow and VPS2 screens so that it compiles at this stage of the tutorial.

The steps in the next pages replace these placeholders. In the `vps2e2e` sample, the fuller startup flow is split across `src/main/java/com/nianticspatial/nsdk/vps2e2ekotlin/MainActivity.kt`, `src/main/java/com/nianticspatial/nsdk/vps2e2ekotlin/LandingView.kt`, and `src/main/java/com/nianticspatial/nsdk/vps2e2ekotlin/NSDKSessionManager.kt`.

## Present authorization

This step adds placeholder authorization UI to the standalone Kotlin tutorial path. In this guide, the app uses a [developer token](https://www.nianticspatial.com/docs/nsdk/auth_developer_token/) in `WayfindingApp.kt` for testing, and the top-level authorization structure that later pages build on. This step shows how you to add authorization state, present authorization UI, and reopen that UI later, even before you implement a full browser-based sign-in flow.

This step adds sign-in state to the app entry flow. Before the app can load organization and Site data, it should check whether the user already has a valid session and present authorization UI if one is not available.

This step has four parts:

1. [Create an auth manager](#create-an-auth-manager) to own authorization state.
2. [Create the auth UI](#create-the-auth-ui) to show sign-in state and actions.
3. [Show the auth sheet](#show-the-auth-sheet) to open the authorization UI when needed.
4. [Reopen authorization](#reopen-authorization) so the user can open the authorization UI later.

### Create an auth manager

In an existing app, update your current authorization manager. If you are unsure how to implement this step, use the following new app example as a reference.

The auth manager should:

- Tracks sign-in state.
- Starts sign-in.
- Signs the user out.
- Exposes the auth state that the UI needs.

In a new app, create a new `WayfindingAuthManager` package under `app/src/main/java/<your app package path>/auth/` as follows:

1. In Android Studio, expand `app/src/main/java`.
2. Expand your app package, for example `com.example.wayfinding`.
3. Open the package menu and select **New > Package**.
4. Enter `auth`.
5. Open the new `auth` package menu and select **New > Kotlin Class/File**.
6. Create `WayfindingAuthManager.kt` inside that package.

The following code example creates a minimal standalone `WayfindingAuthManager` that compiles and gives the rest of the tutorial a working auth state to build on:

#### Expand to view `WayfindingAuthManager.kt`

```kotlin
package com.example.wayfinding.auth // Replace with your app package name and auth package

import android.app.Activity
import androidx.compose.runtime.getValue
import androidx.compose.runtime.mutableStateOf
import androidx.compose.runtime.setValue
import androidx.lifecycle.DefaultLifecycleObserver
import androidx.lifecycle.LifecycleOwner
import com.nianticspatial.nsdk.NSDKSession

class WayfindingAuthManager(
    private val nsdkSession: NSDKSession,
) : DefaultLifecycleObserver {

    // Keep track of whether the user is currently signed in
    var isLoggedIn by mutableStateOf(false)
        private set

    // Show a short status string in the auth UI
    var statusMessage by mutableStateOf("Not Logged In")
        private set

    // Show login controls in this standalone example
    val showLoginControls = true

    // Show the signed-in email address when one is available
    var emailMessage by mutableStateOf("")
        private set

    // Replace this placeholder with your app's real sign-in flow
    fun login(activity: Activity) {
        isLoggedIn = true
        statusMessage = "Logged In"
        emailMessage = ""
    }

    // Sign out and clear the NSDK access token
    fun logout() {
        nsdkSession.setAccessToken("")
        isLoggedIn = false
        statusMessage = "Not Logged In"
```

In a new app, create a new `permissions` package under `app/src/main/java/<your app package path>`, then create `PermissionHelper.kt` in that package to check permission state and request missing permissions:

#### Expand to view `PermissionHelper.kt`

```kotlin
package com.example.wayfinding.permissions // Replace with your app package name

import android.Manifest
import android.app.Activity
import android.content.pm.PackageManager
import androidx.core.app.ActivityCompat
import androidx.core.content.ContextCompat

object PermissionHelper {
    // Request code used by the Android system to identify this permission request
    private const val REQUEST_CODE = 1001
    
    // Check whether all required runtime permissions are already granted
    // Returns true only if both camera and location permissions are available
    fun hasRequiredPermissions(activity: Activity): Boolean {
        val cameraGranted = ContextCompat.checkSelfPermission(
            activity,
            Manifest.permission.CAMERA
        ) == PackageManager.PERMISSION_GRANTED
        val locationGranted = ContextCompat.checkSelfPermission(
            activity,
            Manifest.permission.ACCESS_FINE_LOCATION
        ) == PackageManager.PERMISSION_GRANTED
        return cameraGranted && locationGranted
    }
    // Request any missing permissions from the user
    // This triggers the Android system permission dialog
    fun requestRequiredPermissions(activity: Activity) {
        ActivityCompat.requestPermissions(
            activity,
            arrayOf(
                Manifest.permission.CAMERA,
                Manifest.permission.ACCESS_FINE_LOCATION
            ),
            REQUEST_CODE
        )
    }
}
```

- Request any missing permissions.

1. Add the following imports to the top of `WayfindingApp.kt`:

   ```kotlin

   import androidx.compose.runtime.LaunchedEffect
   import androidx.compose.runtime.mutableStateOf
   import androidx.compose.runtime.setValue
   import androidx.lifecycle.Lifecycle
   import androidx.lifecycle.LifecycleEventObserver
   import com.example.wayfinding.permissions.PermissionHelper
   ```

2. Then, inside `WayfindingApp.kt`, add the following code after the `DisposableEffect(lifecycleOwner, nsdkSessionManager)` block:

   #### Expand to view the permission gate code

   ```kotlin

   var hasPermissions by remember {
       mutableStateOf(PermissionHelper.hasRequiredPermissions(activity))
   }

   // Re-check permissions when the app resumes after the system permission dialog closes
   DisposableEffect(lifecycleOwner) {
       val observer = LifecycleEventObserver { _, event ->
           if (event == Lifecycle.Event.ON_RESUME) {
               hasPermissions = PermissionHelper.hasRequiredPermissions(activity)
           }
       }

       lifecycleOwner.lifecycle.addObserver(observer)
       onDispose {
           lifecycleOwner.lifecycle.removeObserver(observer)
       }
   }

   // Request permissions if they are missing
   // LaunchedEffect ensures this runs when the permission state changes
   LaunchedEffect(hasPermissions) {
       if (!hasPermissions) {
           PermissionHelper.requestRequiredPermissions(activity)
       }
   }

   // Block the rest of the app flow until permissions are granted
   // This prevents navigation into features that depend on camera or location
   if (!hasPermissions) {
       Box(
           modifier = Modifier.fillMaxSize(),
           contentAlignment = Alignment.Center
       ) {
           Text("Requesting permissions...")
       }

       return
   }
   ```

```swift
import AuthenticationServices
import UIKit

final class WayfindingLoginManager: NSObject, ASWebAuthenticationPresentationContextProviding {

    func startAuth() {
        // Build the browser sign-in URL used by the sample auth flow.
        guard let authURL = URL(
            string: AuthConstants.EndPointUrls.SignIn + "?redirectType=\(AuthConstants.callbackUrlScheme)"
        ) else {
            return
        }

        // Open the browser-based sign-in flow and wait for the callback URL.
        let session = ASWebAuthenticationSession(
            url: authURL,
            callbackURLScheme: AuthConstants.callbackUrlScheme
        ) { callbackURL, error in
            if let error = error {
                print("Auth error: \(error.localizedDescription)")
                return
            }
            if let callbackURL {
                self.handleCallback(url: callbackURL)
            }
        }

        session.presentationContextProvider = self
        session.start()
    }

    func presentationAnchor(for session: ASWebAuthenticationSession) -> ASPresentationAnchor {
        // Present the auth browser from the active app window.
        let scene = UIApplication.shared.connectedScenes
            .first { $0.activationState == .foregroundActive } as? UIWindowScene
        return scene?.windows.first { $0.isKeyWindow } ?? ASPresentationAnchor()
    }

    private func handleCallback(url: URL) {
        // Extract the returned sample-session token and store it for the Landing flow.
        let tokens = AuthUtils.extractTokens(from: url.absoluteString)
        NSSampleSessionManager.setNSSampleSession(sessionToken: tokens.refreshToken)
    }
}
```

```swift
private func wayfindingNeedsAuth() -> Bool {
    // Skip the browser auth flow when the current access token is still valid.
    if !AuthUtils.isTokenEmptyOrExpiring(AuthConstants.accessToken, minUnexpiredTimeLeft: 0) {
        return false
    }
    // Otherwise rely on the shared sample-session state.

}
```

```swift
import CoreLocation

final class WayfindingPermissionManager {
    static let shared = WayfindingPermissionManager()

    private let locationManager = CLLocationManager()

    private init() {}

    func requestAllPermissions() {
        // Request the location permission used by the Sites flow.
        requestLocationPermission()
    }

    func requestLocationPermission() {
        guard locationManager.authorizationStatus == .notDetermined else { return }
        locationManager.requestWhenInUseAuthorization()
    }

    var isLocationAuthorized: Bool {
        let status = locationManager.authorizationStatus
        return status == .authorizedWhenInUse || status == .authorizedAlways
    }

    var isLocationDeniedOrRestricted: Bool {
        switch locationManager.authorizationStatus {
        case .denied, .restricted:
            return true
        case .notDetermined, .authorizedWhenInUse, .authorizedAlways:
            return false
        @unknown default:
            return false
        }
    }
}
```

   ```swift
   enum WayfindingNavigationStep: Hashable {
       case sites(nsdkSession: NSDKSession)
       case ar(siteName: String, payload: String, nsdkSession: NSDKSession)

       func hash(into hasher: inout Hasher) {
           switch self {
           case .sites:
               // Hash the Sites route without exposing NSDKSession itself.
               hasher.combine(0)
           case .ar(let siteName, let payload, _):
               // Hash the AR route from the selected Site and payload.
               hasher.combine(1)
               hasher.combine(siteName)
               hasher.combine(payload)

           switch (lhs, rhs) {
           case (.sites, .sites):

           case (.ar(let lName, let lPayload, _), .ar(let rName, let rPayload, _)):
               // Compare only the values that define the AR destination.
               return lName == rName && lPayload == rPayload

           }
       }
   }
   ```

```swift
import Combine
import NSDK

struct WayfindingLandingView: View {

    @State private var navigationPath = NavigationPath()
    @State private var isLoginButtonVisible = false
    @State private var isShowingLocationAlert = false
    @State private var suppressAutoLaunchToMap = false

    @State private var loginManager: WayfindingLoginManager?
    @State private var tokenSubscription: AnyCancellable?
    @State private var cancellables = Set<AnyCancellable>()

    // MARK: - Interaction Functions

    func onViewAppear() {
        print("WayfindingLanding appeared")
        refreshLandingStateForPermissionsAndSession()
    }

    private func refreshLandingStateForPermissionsAndSession() {
        WayfindingPermissionManager.shared.requestAllPermissions()
        print("WayfindingLanding requested permissions")

        NSSampleSessionManager.start()

        if !wayfindingNeedsAuth() {
            if suppressAutoLaunchToMap {
                isLoginButtonVisible = true
            } else {
                launchWayfindingSitesView()
            }
        } else {
            print("WayfindingLanding auth required")
            isLoginButtonVisible = true
        }
    }

    private func startWayfindingLogin() {
        suppressAutoLaunchToMap = false
        print("WayfindingLanding login started")
        NotificationCenter.default.publisher(for: nsSampleSessionDidSetNotification)
            .first()
            .receive(on: DispatchQueue.main)
            .sink { _ in self.launchWayfindingSitesView() }
            .store(in: &cancellables)

        loginManager = WayfindingLoginManager()
        loginManager?.startAuth()
    }

    private func launchWayfindingSitesView() {
        guard navigationPath.isEmpty else { return }
        guard WayfindingPermissionManager.shared.isLocationAuthorized else {
            if WayfindingPermissionManager.shared.isLocationDeniedOrRestricted {
                isShowingLocationAlert = true
            }
            print("WayfindingLanding waiting for location permission")
            return
        }

        let nsdkSession = NSDKSession(
            accessToken: AuthConstants.accessToken,
            useLidar: true
        )
        self.tokenSubscription = NSSampleSessionManager.setupSessionAccess(for: nsdkSession)

        navigationPath.append(WayfindingNavigationStep.sites(nsdkSession: nsdkSession))
        print("WayfindingLanding launched Sites flow")
    }

    private func launchWayfindingARView(siteName: String, payload: String, nsdkSession: NSDKSession) {
        navigationPath.append(WayfindingNavigationStep.ar(siteName: siteName, payload: payload, nsdkSession: nsdkSession))
        print("WayfindingLanding launched AR destination")
    }

    private func wayfindingNeedsAuth() -> Bool {
        if !AuthUtils.isTokenEmptyOrExpiring(AuthConstants.accessToken, minUnexpiredTimeLeft: 0) {
            return false
        }
        return !NSSampleSessionManager.isSessionInProgress
    }

    private func completeWayfindingLogout() {
        NSSampleSessionManager.stopNSSampleSession()
        tokenSubscription = nil
        isLoginButtonVisible = true
        suppressAutoLaunchToMap = true
        navigationPath = NavigationPath()
        print("WayfindingLanding completed logout")
    }

    var body: some View {
        NavigationStack(path: $navigationPath) {
            ZStack {
                // Background Gradient
                LinearGradient(
                    colors: [.white, Color(red: 0.53, green: 0.74, blue: 0.95)],
                    startPoint: .top,
                    endPoint: .bottom
                )

                VStack(spacing: 0) {
                    Spacer()

                    // Icon
                    Image("spatial-icon")
                        .resizable()
                        .aspectRatio(contentMode: .fit)
                        .frame(width: UIScreen.main.bounds.width * 0.45)

                    Spacer().frame(height: 60)

                    // Title
                    Text("Niantic Spatial VPS2\nWayfinding Sample")
                        .font(.system(size: 22, weight: .bold))
                        .foregroundColor(Color(red: 0.26, green: 0.43, blue: 0.71))
                        .multilineTextAlignment(.center)
                        .lineLimit(2)

                    Spacer()

                    // Login Button
                    if isLoginButtonVisible {
                        Button(action: { self.startWayfindingLogin() }) {
                            Text("Sign in to get started")
                                .font(.system(size: 18, weight: .semibold))
                                .foregroundColor(.white)
                                .frame(maxWidth: .infinity)
                                .padding(.vertical, 16)
                                .background(Color(red: 0.27, green: 0.53, blue: 0.82))
                                .cornerRadius(14)
                        }
                        .padding(.horizontal, 32)
                        .padding(.bottom, 40)
                    }
                }
            }
            .navigationBarHidden(true)
            .ignoresSafeArea()
            .onAppear {
                self.onViewAppear()
            }
            .onReceive(NotificationCenter.default.publisher(for: UIApplication.didBecomeActiveNotification)) { _ in
                refreshLandingStateForPermissionsAndSession()
            }
            .alert("Location Access Required", isPresented: $isShowingLocationAlert) {
                Button("Cancel", role: .cancel) { }
                Button("Settings") {
                    if let url = URL(string: UIApplication.openSettingsURLString) {
                        UIApplication.shared.open(url)
                    }
                }
            } message: {
                Text("This app needs location access to function. Please enable it in Settings.")
            }
            .navigationDestination(for: WayfindingNavigationStep.self) { step in
                switch step {
                case .sites(let nsdkSession):
                    self.destinationWayfindingSitesPlaceholderView(nsdkSession: nsdkSession)
                case .ar(let siteName, let payload, let nsdkSession):
                    self.destinationWayfindingVPS2PlaceholderView(siteName: siteName, payload: payload, nsdkSession: nsdkSession)
                }
            }
        }
    }
```
