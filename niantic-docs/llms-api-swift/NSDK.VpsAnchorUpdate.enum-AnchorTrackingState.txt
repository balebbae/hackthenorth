## Declaration

enum AnchorTrackingState

## Summary

Represents the current tracking state of a VPS anchor.
The tracking state indicates how well the system is able to track an anchor's position
and orientation in the current environment.

---

## Cases

| Name | Type | Summary |
| --- | --- | --- |
| case limited | Reason?) | The anchor is being tracked with limited accuracy.Tracking information is available, but is of poor quality and shouldnot be relied upon at close distances. |
| case notTracked | Reason?) | The anchor is not currently being tracked. |
| case tracked | tracked | The anchor is being tracked with full accuracy. |
