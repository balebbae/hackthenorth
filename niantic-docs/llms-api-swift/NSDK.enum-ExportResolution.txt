## Declaration

enum ExportResolution

## Summary

Resolution option for exported scan images.
When exporting a recording, this controls which image resolutions are included in the payload.

---

## Cases

| Name | Type | Summary |
| --- | --- | --- |
| case high | high | Export only the high resolution image when available.This is the same resolution as the camera frame passed to NSDKSession.sendFrame |
| case mixed | mixed | Export both 720p and high resolution images when available. |
| case res720_540 | res720_540 | Export only the 720p resolution image. |
