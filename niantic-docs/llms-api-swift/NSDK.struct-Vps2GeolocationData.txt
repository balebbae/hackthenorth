| Name | Type | Summary |

| var clHeading | CLHeading | The heading represented as a `CLHeading` (via `Vps2Heading`).`trueHeading` is the VPS2-computed heading in degrees clockwise from true north.`headingAccuracy` is derived from `rotationAccuracyDeg`. | var debugDescription | String | A textual representation of this instance, suitable for debugging.Calling this property directly is discouraged.
