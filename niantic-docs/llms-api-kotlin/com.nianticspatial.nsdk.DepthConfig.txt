## Declaration

class DepthConfig

## Summary

Configuration parameters for ARDK's Depth System.

## Basic Usage

```kotlin
val config = DepthConfig(
framerate = 120
featureMode = AwarenessFeatureMode.SMOOTH,
)
ARDK.ConfigureDepth(handle, config)
```

## See also

ARDK.ConfigureDepth
ARDK.CreateDepth

## Properties

| Name | Type | Summary |
| --- | --- | --- |
| featureMode | AwarenessFeatureMode | Specify mode to internally select model for depth estimation. Each modelselects a model that has different performance and quality characteristics.**Default:** `Unspecified` |
| framerate | Int | Framerate which the Depth system takes in input. Depth is an expensivesystem so keeping framerate lower is recommended,**Default:** `10` |
