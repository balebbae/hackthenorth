# NsdkFrame

Source: https://www.nianticspatial.com/docs/api/kotlin/com.nianticspatial.nsdk.NsdkFrame/

NsdkFrame

---

## Declaration

sealed class NsdkFrame

## Summary

Abstraction over the current frame so callers can use one API for both live AR (ARCore [Frame])
and playback ([PlaybackFrame]). Use [camera] for pose, intrinsics, and tracking.
Use [backing] when you need Frame- or PlaybackFrame-specific APIs (e.g. acquireCameraImage).

---

## Properties

| Name | Type | Summary |

| abstract camera | NsdkCamera | - |
| abstract timestamp | Long | Timestamp in nanoseconds when this frame was captured. Matches ARCore [Frame.getTimestamp]. |
