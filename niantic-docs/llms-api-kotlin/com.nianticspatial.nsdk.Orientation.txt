# Orientation

Source: https://www.nianticspatial.com/docs/api/kotlin/com.nianticspatial.nsdk.Orientation/

Orientation

---

## Declaration

enum class Orientation

## Summary

Device orientation when capturing camera frames.
Orientation affects how ARDK interprets camera data and poses.
Ensure the correct orientation is set in [FrameData.screenOrientation]
for accurate tracking and localization.

## See also

FrameData.screenOrientation

## Cases

| Name | Type | Summary |
| --- | --- | --- |
| LANDSCAPE_LEFT | LANDSCAPE_LEFT | Device rotated 90 deg counter-clockwise from portrait (landscape) |
| LANDSCAPE_RIGHT | LANDSCAPE_RIGHT | Device rotated 90 deg clockwise from portrait (landscape) |
| PORTRAIT | PORTRAIT | Device held upright in portrait mode |
| PORTRAIT_UPSIDE_DOWN | PORTRAIT_UPSIDE_DOWN | Device held upside-down in portrait mode |
| UNKNOWN | UNKNOWN | Orientation is unknown or not yet determined |
