NsdkConfiguration

## Declaration

object NsdkConfiguration

## Summary

These are value types used to construct a full NSDK configuration when callers
want explicit control over all parameters (vs. using defaults or JSON file).
The nested types correspond to NSDK C-ABI structs and are intentionally
nullable to allow partial specification
