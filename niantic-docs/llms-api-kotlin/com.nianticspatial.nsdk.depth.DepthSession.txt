## Declaration

class DepthSession

## Summary

Creates a Depth session.
Depth enables your app to get estimated depth information from passed in
camera data. This must be called before using any other Depth functionality.

---

| Name | Type | Summary |
| --- | --- | --- |
| depthUpdates | Flow<NSDKResult<DepthBuffer, AwarenessStatus>> | Flow of depth updates. This is the primary way to receive depth updates in Kotlin. |
