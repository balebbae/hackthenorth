## Declaration

class DeviceMappingSession

## Summary

A session for locally creating VPS maps from AR data.
The device mapping feature provides capabilities for locally building persistent maps that can
be used for Visual Positioning System (VPS) localization. These maps capture the visual features
and spatial structure of an environment.
