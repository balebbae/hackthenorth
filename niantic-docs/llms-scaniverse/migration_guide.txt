# Scaniverse migration guide

Upgrade from legacy Lightship.dev to Scaniverse. Developers managing Lightship content must migrate to continue accessing and managing Sites, scans, VPS maps, and API keys.

Migration moves workspaces, projects, Sites (formerly POIs), scans, VPS maps, and API keys into Scaniverse.

Migrate to Scaniverse to ensure your assets remain fully functional and up to date:

- Use new Scaniverse capabilities: Access VPS 2.0, updated APIs, and improved scanning workflows.
- Seamless transition: Continue using existing workspaces, Sites, scans, and API keys in Scaniverse without disruption.

## Migrate Lightship.dev

Use the [Scaniverse Web](https://scaniverse.nianticspatial.com/) and the [Scaniverse app](https://apps.apple.com/us/app/scaniverse-3d-scanner/id1541433223) to manage and access all migrated Lightship content:

- The Scaniverse Web handles organizations, Sites, VPS maps, and API keys.
- The Scaniverse app captures scans, uploads them to the cloud, and generates assets for testing localization.

Migrate Lightship content to Scaniverse to preserve existing assets and continue using them in VPS experiences without interruption. No re-scanning is required to maintain current behavior.

**What Scaniverse replaces:**

| Legacy Lightship        | Scaniverse Replacement                                    |
|------------------------|-------------------------------------------------------------------|
| Workspace              | Becomes an Organization.                                          |
| Private POI            | Becomes a Private Site.                                             |
| Public POI             | Migrates to a Private Site. Access to public POIs is no longer available. Contributed scans remain accessible. |
| Project                | Converts to a Service Account.                                     |
| Scans                  | Remain as Scans.                                                   |
| API Key                | Remain valid for existing apps.                                     |

### How to migrate to Scaniverse

You must migrate to Scaniverse on your desktop.

1. Navigate to the [Scaniverse Web](https://scaniverse.nianticspatial.com/).
2. Select **Migrate a Lightship account** under the login screen.
3. Enter the email address associated with Niantic Spatial. If needed, log out and sign in with the account associated with your Lightship content.
4. Select **Continue**.
5. Check your inbox for an email from Niantic Spatial. If you don't see it, check your spam or trash folders.
6. Select the **Create Scaniverse Login** button in the Niantic Spatial email.
7. Create a new password for your Scaniverse account.
8. Select **Continue**.

### Key dates

The following dates highlight critical milestones for migration. Adhering to these dates ensures continued access to Scaniverse content without interruption:

| Date               | Action / Guidance                                                                 |
|-------------------|----------------------------------------------------------------------------------|
| February 20, 2026 | Self-serve migration to Scaniverse opened. Developers can start moving Lightship content. |
| After February 20, 2027 | Lightship.dev and Geospatial Browser decommissioned. Self-serve migration is no longer available. Contact support for migration. |

For migration issues, contact support@nianticspatial.com and include your Lightship email.
