## Summary<a href="#summary" class="hash-link" aria-label="Direct link to Summary" title="Direct link to Summary">​</a>

Native bindings for process-wide telemetry publishing: starts/stops ardk::TelemetryPublisher (periodic drain of TelemetrySinkRegistry). Started from NsdkUnityContext when telemetry is enabled; stopped on context shutdown.
