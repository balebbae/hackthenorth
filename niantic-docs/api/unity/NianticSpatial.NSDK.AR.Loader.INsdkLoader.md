## Summary<a href="#summary" class="hash-link" aria-label="Direct link to Summary" title="Direct link to Summary">​</a>

\[Experimental\] INsdkLoader defines an interface through which external subsystems can be registered for loading through NSDK, and to all them to access XRLoaderHelper functionality. The external subsystem loader must implement the INsdkExternalLoader interface. This Interface is experimental so may change or be removed from future versions without warning.
