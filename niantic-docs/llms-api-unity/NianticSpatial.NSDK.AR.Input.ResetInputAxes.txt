# ResetInputAxes

Source: https://www.nianticspatial.com/docs/api/unity/NianticSpatial.NSDK.AR.Input.ResetInputAxes/

ResetInputAxes
Resets all input. After ResetInputAxes all axes return to 0 and all buttons return to 0 for one frame.
