## Declaration

public static class TelemetryPublishingNative

## Summary

Native bindings for process-wide telemetry publishing: starts/stops ardk::TelemetryPublisher
(periodic drain of TelemetrySinkRegistry). Started from
NsdkUnityContext when telemetry is enabled; stopped on context shutdown.
