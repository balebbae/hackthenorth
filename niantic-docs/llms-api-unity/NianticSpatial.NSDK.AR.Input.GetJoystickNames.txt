# GetJoystickNames

Source: https://www.nianticspatial.com/docs/api/unity/NianticSpatial.NSDK.AR.Input.GetJoystickNames/

GetJoystickNames
Retrieves a list of input device names corresponding to the index of an Axis configured within Input Manager.

## Declaration

#### Summary

Retrieves a list of input device names corresponding to the index of an Axis configured within Input Manager.
