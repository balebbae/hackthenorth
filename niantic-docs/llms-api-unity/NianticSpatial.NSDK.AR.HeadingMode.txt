# HeadingMode

Source: https://www.nianticspatial.com/docs/api/unity/NianticSpatial.NSDK.AR.HeadingMode/

HeadingMode

---

## Declaration

public enum HeadingMode

## Summary

Controls how the heading is computed from the device's orientation.
Mirrors native ARDK_HeadingMode.

---

## Fields

| Name | Type | Summary |
| --- | --- | --- |
| static CameraDirection | HeadingMode | Heading from the camera's forward axis (perpendicular to screen). Best when the device is held upright in portrait or landscape. |
| static DeviceTop | HeadingMode | Heading from the top edge of the screen, accounting for display orientation. Best when the device is held face-up or for compass widgets. |
