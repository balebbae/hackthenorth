## Methods

| Name | Type | Summary |
| --- | --- | --- |
| static GetScreenOrientation | ScreenOrientation | Calculates the ScreenOrientation from a camera pose. It is assumed that LandscapeLeft is the natural camera orientation, so for example in identity pose. For the edge case screen facing up it will return Portrait and for screen facing down it will return PortraitUpsideDown. |
